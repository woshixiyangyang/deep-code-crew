# Deep Code Crew

This repository is for the Information Programming Deepening team project.

## Project Topic

Monoalphabetic shift cipher.

The program will:
1. Read original text from a file.
2. Remove all non-letter characters.
3. Encrypt the cleaned text using a shift amount.
4. Group the cipher text every five letters.
5. Decipher the cipher text.
6. Print the cipher text and deciphered text.
